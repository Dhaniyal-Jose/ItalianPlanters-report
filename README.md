# Italian Planters - Monthly Service Report Generator

This is a standalone, client-side web application designed to generate beautiful, standardized monthly landscaping and irrigation service reports for Italian Planters.

## Features

- **No Installation Required**: Runs entirely in your web browser using HTML, CSS, and JavaScript. No servers or backend required.
- **Live Preview**: See your report update in real-time as you type in the editor.
- **Customizable Sections**: Easily toggle sections on or off (e.g., Annual Plan, PPM Tasks, Operational Constraints) using the "Include" checkboxes.
- **Photo Grids with Captions**: Drag-and-drop support for bulk photo uploads. Photos are automatically arranged into clean grids (4x3, 3x3, or custom layouts) and scale perfectly to fit the A4 page.
- **PDF Export**: Generate perfectly paginated A4 PDFs directly from your browser.
- **Excel Export**: Export the report data into an `.xls` spreadsheet for record-keeping and data manipulation.

## How to Download and Run

1. **Download the Code:**
   - Click the green **Code** button at the top of this GitHub repository and select **Download ZIP**.
   - Extract the downloaded ZIP file to a folder on your computer.

2. **Run the Application:**
   - Simply double-click the `index.html` file.
   - It will open in your default web browser. (Google Chrome or Microsoft Edge is highly recommended for the best PDF generation experience).

## How to Use the Generator

1. **Company Details**: Upload your company logo and fill in your company name, tagline, and certifications.
2. **Project Details**: Enter the client name, location, and select the specific month for the report.
3. **Fill Sections**: Go through each section (Annual Plan, Operations Performance, Extra Tasks, etc.) and add your tasks. You can add rows dynamically using the "+ Add" buttons.
4. **Manage Sections**: If you do not need a specific section for this month's report, simply uncheck the **Include** box on the right side of the section header to hide it from the final export.
5. **Upload Photos**:
   - Scroll to the **Photographs** section.
   - Click the upload box or drag-and-drop multiple images directly into it.
   - You can reorder photos by dragging them around. Use the dropdown to select predefined captions or type your own custom captions below each photo.
6. **Exporting**:
   - **⬇ Export PDF**: Clicking this will open your browser's print dialog. Ensure the destination is set to **Save as PDF**, paper size is **A4**, and margins are set to **Default**. The app handles all the pagination and layout for you.
   - **⬇ Export Excel**: Instantly downloads an `.xls` file containing all the structured data and tables from your report.
